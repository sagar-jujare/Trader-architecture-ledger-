# Phase 10 — Pricing and WhatsApp invitation request

The landing page includes monthly membership (₹499) and yearly membership (₹4,999), with the yearly plan saving ₹989 compared to 12 monthly payments. Both pricing cards use a single common WhatsApp invitation-request button.

The button opens WhatsApp chat +91 8088521053 with a prefilled message asking the administrator to generate an invitation link. It does not automatically send a message, issue an invite, or take payment. Admin must manually verify payment and issue the invitation using the existing admin dashboard.

No database migration is required. Preserve existing .env and database.
